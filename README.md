# Vorsorge klar – Altersvorsorgedepot

Responsive deutschsprachige Landingpage zum Finanztip-Video „Lohnt sich das Altersvorsorgedepot?“.

## Enthalten

- Mobile und Desktop-Ansicht
- YouTube-Video, das erst nach Klick als Player geladen wird
- Interaktive Sparsimulation mit Sparrate, Laufzeit und angenommener Rendite
- Fragen zur Entscheidungsfindung und Links zum Finanztip-Rechner

## Starten und bereitstellen

`index.html` direkt im Browser öffnen. Keine Installation und kein Build erforderlich.

Für Vercel: Repository importieren, Framework „Other“ wählen und keinen Build-Befehl einstellen. Die Datei `index.html` liegt im Projektstamm.

## Inhaltliche Grundlage

Grundlage sind Titel und Beschreibung des Videos https://youtu.be/sp-ICerulRg, abgerufen am 20.10.2026. Der gesprochene Inhalt wurde nicht vollständig ausgewertet. Keine offizielle Finanztip-Seite.

Die Sparsimulation ist eine eigene Modellrechnung mit monatlicher Einzahlung am Monatsende und konstanter angenommener effektiver Jahresrendite. Förderung, Steuern, Gebühren und Inflation sind nicht berücksichtigt. Sie ist kein AV-Depot-Rechner und keine persönliche Anlageberatung.
